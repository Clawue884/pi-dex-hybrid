# 🏛️ Governance — pi-dex-hybrid

**pi-dex-hybrid** is a community-driven open-source project for the Pi ecosystem.  
Governance defines how decisions are made and how the project evolves.

---

## 🎯 Principles

- Open participation
- Transparency
- Security-first
- Community alignment

---

## 🧩 Roles

### 🧑‍💻 Maintainers
- Review & merge PRs
- Maintain architecture
- Ensure security & quality

### 🧪 Contributors
- Submit PRs
- Propose features
- Improve docs & tests

### 🌍 Community
- Discuss ideas
- Report issues
- Provide feedback

---

## 🗳️ Decision Making

- Minor changes → Maintainers decide
- Major features / breaking changes → Proposal + community discussion
- Security-sensitive changes → Maintainers + security leads

---

## 📜 Proposal Process

1. Open an Issue with label `proposal`
2. Describe:
   - Motivation
   - Design
   - Impact
3. Discussion (7–14 days)
4. Decision & merge

---

## 🔐 Emergency Powers

In case of critical security risks:
- Maintainers may patch immediately
- Disclosure follows after fix

---

## 🔮 Toward DAO (Future)

pi-dex-hybrid plans to evolve into:

- On-chain governance
- Token-based voting
- Community treasury

---

## 📣 Communication

- GitHub Issues / Discussions
- Docs updates

---

Governance is about trust + process.  
**Build together. Decide openly. 🏛️**
