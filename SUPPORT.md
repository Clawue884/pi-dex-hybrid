# 🆘 Support — pi-dex-hybrid

Welcome to **pi-dex-hybrid** support!  
This document explains how to get help, report issues, and stay informed.

---

## 📌 Getting Help

If you need help with:

- Setup & installation
- Running the app locally
- Deployment to production
- Contributing
- Understanding the architecture

You can:

1. Check the documentation in `/docs`
2. Read the `README.md`
3. Search existing GitHub Issues

---

## 🐞 Reporting Bugs

If you find a bug:

1. Go to the **Issues** tab
2. Click **New Issue**
3. Use the **Bug Report** template
4. Include:
   - Steps to reproduce
   - Expected vs actual behavior
   - Logs / screenshots
   - Environment (OS, Docker version, Node/Python version)

---

## 💡 Feature Requests

Have an idea?

1. Open an Issue with label `enhancement` or `proposal`
2. Describe:
   - Use case
   - Benefit
   - Possible solution

---

## 🔐 Security Issues

⚠️ Do **NOT** report security issues publicly.

Instead, follow `SECURITY.md` and email:

📧 **security@pi-hybrid.org**  
(Replace with your real security contact)
