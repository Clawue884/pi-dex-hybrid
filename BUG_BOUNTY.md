# 🏅 Bug Bounty Program — pi-dex-hybrid

We believe security is a community effort.  
The **pi-dex-hybrid Bug Bounty Program** rewards responsible security research that helps keep users safe.

---

## 🎯 Scope

In-scope components:

- AMM Engine (NestJS / TypeScript)
- Orderbook Engine (FastAPI / Python)
- Settlement Workers
- API & WebSocket layer
- Frontend (React + Pi SDK)
- Docker, Nginx, and deployment configs

Out-of-scope:

- Social engineering
- DoS / traffic flooding
- Physical attacks
- Issues in third-party libs unless directly exploitable in this project

---

## 🧪 What to Report

- Smart logic flaws in AMM or Orderbook
- Trade / settlement manipulation
- Auth / session / signature issues
- Data leaks
- Privilege escalation
- Replay attacks

---

## 💰 Rewards (Planned)

Severity | Example | Reward
-------- | ------- | -------
Low      | Minor info leak | Swag / Credits
Medium   | Auth bypass | $100 – $300
High     | Fund loss / trade manipulation | $500 – $2,000
Critical | Full system compromise | $2,000+

> Rewards are discretionary and depend on impact, quality of report, and fixability.

## ⏱️ Process

1. We acknowledge within **72 hours**
2. We investigate and validate
3. We fix and deploy a patch
4. We coordinate disclosure
