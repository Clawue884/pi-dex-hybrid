# 🤝 Contributing to pi-dex-hybrid

Thank you for your interest in contributing to **pi-dex-hybrid**!  
We welcome developers, researchers, designers, and community members.

---

## 📌 Ways to Contribute

- Fix bugs
- Improve documentation
- Add features (AMM, Orderbook, UI, infra)
- Write tests
- Review pull requests
- Propose ideas & architecture

---

## 🛠️ Development Setup

```bash
git clone https://github.com/Clawue884/pi-dex-hybrid.git
cd pi-dex-hybrid
docker compose up --build
🔁 Workflow
Fork the repository
Create a new branch:
git checkout -b feat/my-feature
Make your changes
Commit with a clear message:
git commit -m "feat: add matching engine improvement"
Push:
git push origin feat/my-feature
Open a Pull Request
🧪 Code Standards
TypeScript: follow NestJS conventions
Python: follow PEP8
Use clear naming and comments
Add tests where possible
🔍 Review Process
PRs are reviewed by maintainers
CI must pass before merge
Feedback may be requested
🧠 Communication
Use GitHub Issues for bugs & proposals
Be respectful and constructive
Thanks for helping build the future of Pi DeFi 🚀
